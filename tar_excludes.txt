# =============================================================================
# tar_excludes.txt —— 大目录 / 权重 / 缓存 / 临时文件排除清单
#
# 用于「把仓库打成快照交给其他环境」的场景。
# 注：`force_push_github.sh` **不使用**本文件（它靠 .gitignore + `git add -A` 建树）。
#
# ⚠️ 调用约定（必须满足，否则下文的 `./` 锚定条目会**全部失效、权重全打进快照**）
# -----------------------------------------------------------------------------
# 必须在「仓库根」打包，使归档成员名以 `./` 开头：
#
#     cd /workspace/Video_Enhancement
#     tar -czf ../snapshot.tgz --exclude-from=tar_excludes.txt .
#
# 为什么：以 `./` 开头的条目是「只排根级、保留嵌套同名目录」的锚定模式。
# 2026-09-23 GNU tar 实测：
#   - 成员 `./models/...` + 模式 `./models` → 命中根级，且保留
#     `./external/IFRNet/models/`（架构源码）                        ✅ 正确
#   - 成员 `./models/...` + 模式 `/models`  → **什么都不匹配**，
#     权重会全部进快照                                              ❌ 危险
#   - 成员 `./models/...` + 模式 `models`   → 任意层级命中，把
#     `external/IFRNet/models/` 等源码目录一并排掉（历史事故根因）   ❌ 错误
#   - `--anchored models`，或成员带外壳目录名（`Video_Enhancement/...`）
#     → 同样匹配不到，权重全进快照                                  ❌ 危险
#
# 自检（每次打包后跑，**必须为 0**；非 0 说明调用约定不对）：
#     tar -tzf <snapshot>.tgz \
#       | grep -cE '(^|/)(models|models_[^/]*|temp|tmp|logs|output|archive)/|\.(pth|trt|onnx|safetensors|ckpt)$'
#
# 更省事的替代（推荐）：`git archive` 只含已跟踪文件，天然无权重/缓存/转储：
#     git archive --format=tar.gz -o ../snapshot.tgz HEAD
# =============================================================================
