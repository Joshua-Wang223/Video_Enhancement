# v6.4.5/.1 bitrate=unconstrained 性能塌方

## 现象

Batch (CRF=23) vs Individual (CRF=21) 运行出现矛盾:

| 版本 | Batch FPS | Individual FPS | 退步 | GPU利用率 | 空闲占比 |
|------|----------:|---------------:|:----:|:---------:|:-------:|
| v6.4.5 VBR_HQ | 64.1 | **18.9** | **2.2× 慢** | 35.5% | 65.0% |
| v6.4.5.1 QVBR | 64.1 | **27.9** | 1.4× 慢 | 31.3% | 70.0% |
| v6.4.3.1 VBR_HQ | 61.4 | ~60+ | 正常 | 52.0% | 47.6% |

## 根因

对比 NVENC RC 参数初始化代码:

**v6.4.3.1** (`process_video_v6_4_3_1_single.py:1222-1224`):
```python
_est_br = max(50000000, int(width * height * fps * 3.0))  # 720*576*50*3 ≈ 62Mbps
rc_ptr[5] = _est_br           # averageBitRate = 62208kbps
rc_ptr[6] = _est_br * 2       # maxBitRate = 124416kbps
```

**v6.4.5/.1** (`process_video_v6_4_5_1_single.py:1256-1259`):
```python
# 当 targetQuality 启用时，averageBitRate/maxBitRate 置零，
# 让编码器完全由 targetQuality 驱动质量
rc_ptr[5] = 0                 # averageBitRate = 0
rc_ptr[6] = 0                 # maxBitRate = 0 (无上限)
```

**结果**: `averageBitRate=0` + `maxBitRate=0` + `targetQuality=21 (高质量)` 
→ NVENC SDK 在无码率天花板情况下，为达到 targetQuality=21 进入极端的
穷举搜索/反复迭代模式，编码速度暴跌 ~3×。

## 为什么 Batch 不受影响？

Batch (CRF=23) 中 v6.4.5 日志显示 `VBR_HQ` (无LA)，individual (CRF=21) 中
也显示 `VBR_HQ` (无LA)。但 Batch 的 `benchmark_ifrnet_versions.py` 可能通过
不同的参数路径设置 `avgBitrate`（如 `_NVENC_LEVEL1_RATE_MODE` + 自动估计）。

需要进一步排查 benchmark script 中编码器参数传递路径。

## 修复方案

恢复 v6.4.3.1 的 avgBitrate 设置逻辑 — 提供合理的天花板值，但不限制 NVENC
在 targetQuality 下的质量优化:

```python
# VBR_HQ 分支修复:
if self._rate_mode == 'vbr_hq':
    rc_ptr[1] = 32  # NV_ENC_PARAMS_RC_VBR_HQ
    # [FIX-BR-CEILING] avgBitRate 作为速度天花板而非质量限制
    # NVENC 在 targetQuality 驱动下尽力达到 CRF 质量，但用 avgBitRate
    # 防止无界慢速穷举优化
    _est_br = max(50000000, int(width * height * fps * 3.0))
    rc_ptr[5] = _est_br       # averageBitRate
    rc_ptr[6] = _est_br * 2   # maxBitRate
    ... targetQuality 设置保持不变 ...
```

## QVBR 的 maxBitRate 已有设置

v6.4.5.1 QVBR 分支中 `maxBitRate` 已设置有值 (`rc_ptr[6] = _est_br`)，
但 `averageBitRate = 0` 仍存在。对于 QVBR，NVENC SDK 文档建议同时设置
`averageBitRate`（即使宽松）。建议:

```python
elif self._rate_mode == 'qvbr':
    rc_ptr[1] = 64  # NV_ENC_PARAMS_RC_QVBR
    _est_br = max(50000000, int(width * height * fps * 3.0))
    rc_ptr[5] = _est_br       # [FIX-BR-CEILING] averageBitRate
    rc_ptr[6] = _est_br       # maxBitRate
```
