裁定一个 FAIL 是否闭环（或判"是伪影/噪声"）前，**参与比较的量必须落在同一口径**：
同 OLS 窗口、同 batch_size、同素材/时长、同测量方式。跨口径的"数值接近"**不构成证据**。

**Why（2026-10-06 复核 L40 AV1 专项 S8 内存斜率）**：
- S8 判据是用 **后半程（后 50%）RSS OLS 斜率**；L40 当次脚本（`b64c1d2` 的
  `half = rows[len//2:]`）亦然 ⇒ 其 **+149.5 是后 50% 口径**。
- 文档/记忆却拿 **T4 的"全程 +149.4"** 去类比 L40 的"后 50% +149.5"，得
  「几乎相同 ⇒ 窗口伪影」——**两者窗口不同，这个对比无效**。
- 同一份 `hevc_constqp` 原始数据换窗口可得 前 10% +1434.2 / 后 50% +3.1 / 全程 +149.4 /
  末 10% −786.7 ⇒ 窗口敏感是真的，但"证明"它的那条推理是错的。
- 另：记忆里「不确定度约 ±66 MB/min」是**残差 sd(≈1356 MB)** 的量级，**不是斜率标准误**；
  实测后 50% 斜率 SE ≈ ±8~15（95%CI ≈ ±20~30）⇒ +50 阈值约 3σ，**+149.5 不是噪声**。

**How to apply**：
- 要判"某 FAIL 是伪影/噪声"，**必须能在同一口径上复现该数字**；只能跨口径得到"相似数字"时，
  结论降级为「**不可复现 / 风险接受**」，不得写成「根因已解释 = 窗口伪影」。
- 报斜率/趋势类结论时同时给**窗口 + 斜率标准误(SE)**，别把残差 sd 当不确定度（差 √Sxx 倍）。
- 闭环证据不足时如实分两档：**工程闭环（不可复现/风险接受）** ≠ **根因闭环（已解释）**，
  并写明残余（如"原始采样未落盘、无法复算"）。
- 归档原始采样（`--mem-dump-dir`）的额外价值：**让闭环判定可离线复算**，否则只能类比推断。
