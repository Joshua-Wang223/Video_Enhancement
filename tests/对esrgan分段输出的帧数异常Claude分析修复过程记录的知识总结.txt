修复要点

- Bug 1: 删掉 _frame_idx=0 / _output_slot_idx=0 重置（保留 _slots_warmed=set()），保持跨段连续递增
- Bug 2: 双缓冲环形池 + per-slot CUDA event 追踪 + wait_output_ready() 同步
- Bug 3: _ensure_slot_free() 提交前背压检查 + 共用 _apply_drained_entries()
- Bug 4: if n_frames == 0 and not send_eos: return []

所有修复已通过 Linux 生产环境验证，帧序正确、无乱序花屏重复。
